# Agent Note: 当前 Cordis 研究范围

Status: implemented

[English](2026-09-10-current-cordis-study-scope.md) | 中文

## 问题

Fork 的阅读路径需要明确读者能验证哪份实现和哪些结论。将历史模型结果与当前论文术语混合，会使“通过”的含义不清晰。

## 决策

[Fork 指南](../../../../docs/cordis-study.zh.md)引导读者依次查看当前论文、选定的 fork 源码和具体生命周期检查。外部研究门户负责精确版本锁、共用可执行检查、生成报告和研究归档快照。

指南区分提供官方源码的默认分支与锁定的 fork 实现，说明被检查的依赖清理、退休组件可发现性和提供方身份行为，并明确限定到这些场景。整个应用的行为和完整演算的证明不属于这些结果。

## 考虑过的替代方案

**在主指南中保留历史分支矩阵。** 这要求新读者在定位当前源码前先了解实验历史。门户归档保留这些历史及其限定说明。

**将通过的模型运行称作当前论文验证。** 历史可执行模型没有编码完整的当前演算。直接实现检查支持指南所作的较窄陈述。

## 影响

读者只需跟随一个版本与证据维护入口。Harness 指南链接到该入口，不重复统计，也不将历史 mismatch 发布为当前结论。此次文档调整不影响 fork 运行时或历史研究提交。

中英文指南和首页入口通过翻译配对与仓库文档检查一起维护。对活动笔记的定向审阅未发现需要被替代的本 fork 阅读决策记录。
